# D01 technical feasibility

Begin after PREP-05 owner approval. Use a disposable official Tauri v2 React/TypeScript scaffold outside the repository, with the identifier `com.shadowmind.feasibility`. Use the verified reference desktop and record the exact environment, manifests and lockfiles. The probe will use a deterministic mock provider and USD 0 paid spend. See the [D01 feasibility evidence](D01-EVIDENCE.md) for current outcomes and limitations.

Use self-created visual and spoken fixtures. Record each fixture's version, provenance, permitted scope and expected outcome. Obtain any source or participant approvals before a native check. Observe OS permission prompts and visible session controls. Keep test data local and limit evidence to sanitized observations and measurements.
